## The invisible stream you never asked for

When I opened Claude Code this morning, the status panel showed a three‑word line that looked harmless. I didn’t notice a timer firing every thirty seconds, silently sending the entire transcript of each background agent back to Anthropic’s Opus model. The result is a data‑collection pipeline that lives entirely outside the user‑visible conversation.

The leak was first spotted by DRIM in Claude Code’s OpenTelemetry export. By grouping `claude_code.api_request` events by `query_source`, DRIM found that requests labeled `agent_summary` accounted for 16.4 % of total spend, almost the same share as the main conversation itself. In practice that means roughly one in five API calls originates from an internal summary request, not from a user.

## Token economics that bite your rate limits

Claude Code estimates cost in `cost_usd` per request, even on a flat‑rate subscription. The hidden summary calls consume about 15‑20 % of your token budget for a typical session. The ratio of input tokens to output tokens is staggering, roughly nine thousand to one, because the model is asked only to produce a three‑to‑five‑word status line.

That inefficiency translates directly into lost headroom. If you are throttled by rate limits, the silent agents eat the bandwidth you could have used for real user interactions. The effect is amplified by the fact that 96 % of the summary traffic lands on Opus, Anthropic’s most expensive model tier.

## Strategic implications: moat or regulator’s nightmare

From a strategic angle the leak is a double‑edged sword. On one side, Anthropic now possesses a continuous feed of real‑world workflows, code snippets, and proprietary data that developers run through Claude Code. That feed could become a competitive moat if Anthropic trains future models on it without explicit consent.

On the other side, emerging AI‑privacy regulations in the EU, US, and Asia are beginning to treat any unsolicited transmission of user or corporate data as a breach. The fact that the data never leaves the local machine in a user‑visible form does not shield a company from liability. A regulator could view the background agent telemetry as a hidden data export, triggering fines and forced audits.

## What product teams must audit today

Most teams audit only the inputs that reach the public API. The Claude Code case shows that internal telemetry can be just as risky. The first step is to instrument your own OpenTelemetry pipeline and filter by `query_source`. Look for any request that does not originate from a user‑initiated action.

If you are using Claude Code, the community‑maintained `no-agent-summary.js` Bun preload offers a concrete fix. The script intercepts the global `setTimeout` that powers the summary timer and replaces it with an inert handle. Because the preload runs before the binary’s bytecode, it does not require patching the binary itself. After installing the script, verify that `agent_summary` events disappear from your telemetry.

Even with the fix, you should treat any background telemetry as a feature that needs a privacy flag. Document the data flow, expose a toggle in your product settings, and include it in your data‑processing agreements. In regulated markets, you may need to obtain explicit consent before any internal agent can transmit content.

## A principle for AI‑first products

If you cannot see a data path, you cannot control it. The Claude Code leak proves that invisible telemetry can erode both your unit economics and your compliance posture. Treat every background process as a potential external API call and audit it with the same rigor you apply to user‑facing endpoints.

The next time a new AI SDK lands on your stack, ask yourself: does it whisper to the cloud every time it updates a status line? If the answer is yes, you have a hidden cost center and a regulatory exposure that needs immediate attention.

**Takeaway:** Build a telemetry‑visibility checklist into your product launch process; the cost of a three‑word status line is far higher than its length suggests.
