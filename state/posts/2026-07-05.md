The most valuable asset in AI isn’t the model. It’s the prompt. Not the one you type in. Not the one users see. The hidden, meticulously engineered system prompt, the invisible script that tells Claude Code to use Glob and Grep before writing a line of code, or that tells GPT-5.5 Thinking to pause, reason step by step, then double-check its own logic before responding. These aren’t settings. They’re product DNA.

Last week, a GitHub repo called system_prompts_leaks went viral. It didn’t leak weights. It didn’t leak training data. It leaked the exact instructions Anthropic, OpenAI, and Google use to make their models behave like products, not just predictors. Claude 3.5 Sonnet’s prompt now sits alongside GPT-5.5 Codex’s. Gemini 3.5 Flash’s tool-use rules are visible. Every AI startup is reverse-engineering them. This isn’t a breach. It’s a revelation.

For years, we assumed the moat was in model scale. Bigger parameters. More training data. Higher benchmark scores. But the real differentiator is how the model is framed. Claude 3.5 Sonnet solves 64% of coding tasks in internal agentic evaluations. Claude 3 Opus solved 38%. That’s not because Sonnet is smarter. It’s because its system prompt changed how it approaches tool use, when to defer, how to structure artifacts, and when to stop and reflect. Compare that to GPT-5.5 Codex. Its system prompt doesn’t just say ‘write code.’ It says ‘assume the user is a senior engineer working on a legacy Python codebase. Prioritize backward compatibility. Use type hints. Never refactor without a test.’ That’s not a capability. That’s a product philosophy encoded in 3,000 words.

Anthropic’s system prompts are built around constitutional principles. Privacy. Safety. Tool use boundaries. They’re not just rules, they’re brand values. OpenAI’s prompts are optimized for speed, depth, and context-awareness. Gemini’s lean into multimodal clarity. These aren’t tweaks. They’re strategic choices. And now they’re public.

Every startup building an AI agent, whether for customer support, legal research, or software engineering, now has a blueprint. You don’t need to train a new model. You just need to steal the right prompt structure. You can copy how Claude Code uses Glob to search files before writing code. You can mimic how GPT-5.5 Thinking forces itself to write out reasoning before answering. You can replicate the exact phrasing that makes Claude 3.5 Sonnet trigger a wireframe generation after a single sketch description.

The race isn’t for bigger models anymore. It’s for better framing.

What does this mean for product teams? First, stop treating prompts as configs. They’re product features. The difference between Claude Code and GPT-5.5 Codex isn’t just model performance. It’s whether the system prompt says ‘generate a solution’ or ‘generate a solution, then validate it against the project’s test suite.’ One is a tool. The other is an engineer.

Second, if you’re building on top of an API, you’re not just buying compute. You’re buying a personality. And that personality is locked behind a system prompt you can’t change. If your product needs a cautious, reasoning-heavy assistant, but you’re using a model whose prompt prioritizes speed, you’re building on sand.

Third, the next wave of AI startups won’t be built on fine-tuned weights. They’ll be built on prompt orchestration. The winners will be the ones who can layer their own rules on top of leaked system prompts, adding custom tool chains, enforcing domain-specific constraints, or suppressing unwanted behaviors. The model is the engine. The system prompt is the transmission.

This is the new open source. We used to think the future of AI was in open weights. It’s not. It’s in open prompts. The most valuable code isn’t in PyTorch. It’s in the carefully worded paragraph that tells an AI when to say no, when to ask for clarification, and how to think before acting.

The next time someone says ‘I’m training a better model,’ ask them: what’s your system prompt doing that the others aren’t? Because the model is just a mirror. The prompt is the lens. And now, the lens is exposed.
